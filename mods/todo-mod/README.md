# todo-mod

**한국어** | [English](README.en.md)

저장소(git 루트)마다 할 일 목록을 하나씩 두고 옆 패널에 보여 준다. 목록은 세션이 바뀌어도 그 저장소에 남는다. 메인 세션 하나를 오래 쓰다가 대화가 요약(컴팩션)되거나 작업 중에 다른 요청이 끼어들어도, 끝나지 않은 일을 Claude가 잊지 않게 붙잡아 두는 것이 목적이다.

- **끼어든 요청 붙잡기:** Claude가 일하는 도중에 메시지를 보내면, 하던 일(▶)과 새 요청(☐)을 목록에 자동으로 올린다.
- **매 프롬프트에 일깨우기:** 끝나지 않은 항목이 있으면 프롬프트를 보낼 때마다 그 목록과 "임의로 버리지 않는다"는 당부를 Claude에게 함께 보낸다. 강제로 막지는 않는다.
- **Claude가 직접 관리:** Claude는 `todo` 도구로 항목을 추가하고 진행 중·완료로 바꾼다. 완료 여부는 Claude가 판단한다.
- **저장소 기준:** 세션의 프로젝트 루트에서 `git rev-parse --show-toplevel`로 찾은 경로를 키로 `$.store`에 저장한다. git 저장소가 아니면 프로젝트 루트를 쓴다. Orca worktree는 worktree마다 목록이 따로 생긴다.
- **위치 이동:** `/cd`나 worktree 이동으로 프로젝트 루트가 바뀌면 2초 안에 그 저장소의 목록으로 바뀐다. 셸에서 `cd`(`!cd`, Claude의 Bash)로 옮기는 것은 따라가지 않는다.
- **패널:** 맨 위에 저장소 이름, 그 아래 진행 중·대기·완료 박스, 맨 아래 상태에 따라 표정이 바뀌는 고양이가 있다.

```sh
claude plugin install todo-mod@claude-hub
```

## 쓰는 법

| 명령 | 하는 일 |
|---|---|
| `/todo-mod` | 패널을 열고 목록을 보여 줌 |
| `/todo-mod <내용>` | 할 일 추가(대기 ☐) |
| `/todo-mod start <번호>` | 진행 중(▶)으로 |
| `/todo-mod done <번호>` | 완료(✔)로 |
| `/todo-mod rm <번호>` | 지우기 |
| `/todo-mod clear` | 완료한 항목 모두 지우기 |

패널에서는 항목 앞 표시(☐ ▶ ✔)를 눌러 상태를 돌리고, `×`로 지우고, 완료 박스의 `[완료 정리]`로 완료 항목을 지운다.

`/todo-mod`로 직접 넣은 항목은 메모일 뿐이다. Claude에게 시키려면 "3번 해줘"처럼 말로 지시한다.

## 알려진 한계

- 끼어든 메시지가 새 일인지, 하던 일에 대한 정정이나 잡담인지 구분하지 않고 모두 올린다.
- 항목 이름은 프롬프트의 첫 줄(최대 60자)을 쓴다. 첫 줄이 인사말이면 그 말이 이름이 된다.

## 테스트

```sh
claude plugin test mods/todo-mod
```

## 출처

지인이 공유해 준 session-todo mod(세션 단위 할 일 패널)를 허락을 받아 바탕으로 삼고, 저장소 단위 저장과 위치 이동 반영, 완료 박스, 저장소 이름 줄을 더했다.
